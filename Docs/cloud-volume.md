# 云体积

**云体积**（`ADreamCloudVolume`）是一团放在关卡里的云：给它一个网格或几个图元，它就变成那个形状的云。
拖动、旋转、缩放都实时跟着走；镜头可以飞进去，角色和飞机可以在里面挖出通道，过一阵再长回来。

它适合**近处、有边界的云**：主角云（鲸鱼、城堡这类造型云）、低空能穿过去的云、山腰的云、挡在建筑前面的云。
几公里以上的大片云层和积雨云交给天空（`ADreamSky` 的云），见文末「限制」。

| | |
| :-- | :-- |
| Actor | `ADreamCloudVolume`（根组件 `UDreamCloudVolumeComponent`） |
| 挖洞组件 | `UDreamCloudCarverComponent` |
| 模块 | `DreamCloud`（Runtime） |
| 材质 | `/DreamDynamicWorld/Cloud/M_DreamCloudVolume` |
| 测试关卡 | `/DreamDynamicWorld/Cloud/Maps/Lvl_DreamCloudVolumeTest` |
| 控制台前缀 | `DreamCloud.` |

## 快速开始

1. 在关卡里放一个 **Dream Cloud Volume**。默认是一个半径 5 米的球形云。
2. 在 **Cloud ▸ Shape** 里选形状来源：
   - **Primitives**：编辑球、盒、胶囊的列表；
   - **Mesh**：指定一个静态网格。
3. 在 **Cloud ▸ Appearance** 里选外观：**Realistic**（写实）、**Toon**（卡通）、**Painted**（新海诚）。
4. 拖动、缩放，看效果。改了形状才会重新烘焙，移动、旋转、缩放不会。

关卡里要有 `ADreamSky`：云体积的太阳、天空光和卡通色调都从插件的共享参数集合（`MPC_DreamDynamicWorld`）里读，
和天空的云用同一组光。

## 形状

形状先烘焙成一个**有符号距离场**：一个包住形状的盒子，切成立方体格子，每格存到形状表面的距离（里面为负）。
材质在这个盒子里沿视线步进：远离云的地方按距离大步跳过，靠近云的地方改细步。

### 图元

`Primitives` 是一组 `FDreamCloudPrimitiveShape`：

| 字段 | 含义 |
| :-- | :-- |
| `Type` | `Sphere` 球、`Box` 圆角盒、`Capsule` 胶囊 |
| `Transform` | 在组件里的位置和朝向（缩放不起作用，大小看 `Size`） |
| `Size` | 球：X = 半径；盒：三个半边长；胶囊：X = 半径，Z = 中段半长（厘米） |
| `Rounding` | 盒的圆角（厘米） |
| `bSubtract` | 从别的图元里挖掉它（隧道、空洞） |

`PrimitiveBlend`（厘米）是图元之间接缝的圆滑程度，0 为硬拼接；挖掉的图元用同样的圆滑。
图元的场在加载时现烘（几毫秒），不存进关卡。

### 网格

`ShapeMesh` 指定一个静态网格，以组件的局部空间为准。

- **闭合网格效果最好**；不闭合的网格由三个轴向的射线投票判断里外，大多数情况也能用。
- **合并网格**（几个闭合零件互相插在一起）会按零件分别算距离再取并集，零件互相插进去的面不会在云里留下缝。
  零件超过 16 个时整体计算，每个零件按自己包住的体积统一朝向。
- 网格的场**存进关卡**：每格一个字节（精度是十六分之一格，离表面 8 格以外截断），再压缩。
  一个 64³ 的方块云不到 2 KB。
- 在**编辑器**里，网格重新导入后会自动重烘。**游戏里**只在关卡里没有场时才烘，
  这时网格要开 **Allow CPU Access**，否则读不到三角形。

### 烘焙设置

| 属性 | 默认 | 说明 |
| :-- | :-- | :-- |
| `Resolution` | 96 | 场在盒子最长边上的格数（16–256）；越大越细，烘焙越慢、占用越多 |
| `Padding` | 0.15 | 形状四周留出的空间，按形状最大边长的比例；云膨胀（`Inflate`）和噪声只在这范围内有效 |

`Field` 在高级显示里能看到烘好的格数、中心和大小。蓝图或代码改了形状后调 `Rebake()`；
只改了外观参数时调 `UpdateCloudMaterial()`。

## 外观

| 外观 | 画法 |
| :-- | :-- |
| **Realistic** 写实 | 当作参与介质积分：太阳光穿过云的自阴影，前后两个散射瓣加多次散射近似，天空光从顶到底减弱。逆光时薄边透亮，背光面和底部变暗 |
| **Toon** 卡通 | 找到云的表面并细化，按叶团尺度取法线，涂成亮、中、暗三个色调，色调交界平滑、跟着鼓包起伏；轮廓按射线离表面多近做抗锯齿。镜头在云里时，周围的云显示成雾，穿出后接着画下一层表面（例如隧道壁） |
| **Painted** 新海诚 | 比写实更密的体积，把穿过云的光和高度当作亮度，用卡通三色调上色，薄边逆光有银边 |

卡通和新海诚用天空样式里的云色调（`CloudLit` 亮、`CloudShadow` 暗，中间调在两者之间）；写实用主光和天空光的颜色。

| 属性 | 默认 | 说明 |
| :-- | :-- | :-- |
| `Look` | Realistic | 外观 |
| `Inflate` | 0 | 云比形状表面向外多长出多少（厘米，负数向里缩） |
| `EdgeSoftness` | 50 | 从表面往里，密度在多深的距离内升到满（厘米）；大了边缘像烟 |
| `Extinction` | 1.5 | 满密度时每米的消光（写实、新海诚）。真实积云约 0.04–0.2，但几十米的云要大一些才成团 |
| `SunStrength` | 2.0 | 太阳光的倍数 |
| `AmbientStrength` | 1.0 | 天空光的倍数 |
| `LitTint` / `ShadeTint` | 白 | 亮面、暗面的染色 |
| `LobeScale` | 200 | 卡通：色调跟随的叶团大小（厘米） |
| `ToneSoftness` | 0.03 | 卡通：色调交界的柔和程度 |

## 噪声

云的边缘被 3D 噪声（天空的云用的同一张 `T_DreamCloudNoise`）侵蚀出鼓包。噪声只会吃掉云、不会加云。
噪声尺寸按世界厘米计，所以云放大后鼓包大小不变、数量变多。

| 属性 | 默认 | 说明 |
| :-- | :-- | :-- |
| `NoiseScale` | 1500 | 噪声一块的大小（厘米），最细的鼓包约为它的八分之一；镜头附近 40 米内再加一层四分之一大小的细节 |
| `NoiseErosion` | 250 | 噪声往云里吃多深（厘米），0 为形状本身的光滑表面 |
| `NoiseDrift` | (20, 0, 5) | 噪声在云里漂移的速度（厘米/秒，组件空间），云就地翻涌 |

## 光照

每个云体积有一张**透射率图**：盒子上的一个小 3D 网格，存从每格朝主光（太阳或月亮）看过去的透射率，由计算着色器绘制。
材质的每个采样直接读这张图，不用再朝光步进。以下情况会重新绘制：

- 光在云里转过 `LightUpdateAngle`（默认 1°）；
- 云旋转了；
- 消光、`Inflate`、`EdgeSoftness`、噪声参数改了；
- 噪声漂移超过半个格子；
- 挖洞变化，最多每秒 10 次。

透射率图包含噪声的低频部分，鼓包这一级的细节平均掉了。
`DreamCloud.UseLightMap 0` 可以改成每个采样朝光取几次样，用来对比。

## 挖洞

给角色、飞机、船挂一个 **`UDreamCloudCarverComponent`**：它每帧把从上一帧到这一帧扫过的胶囊从经过的云体积里挖掉，洞壁带噪声。
人走过去之后，洞保持一会儿再慢慢长回来。

| 挖洞组件属性 | 默认 | 说明 |
| :-- | :-- | :-- |
| `Radius` | 200 | 挖出的通道半径（厘米） |
| `Strength` | 1 | 挖得多干净（1 为完全挖空） |
| `bCarving` | 开 | 关掉就不挖 |

| 云体积属性 | 默认 | 说明 |
| :-- | :-- | :-- |
| `bCarvable` | 开 | 这团云能不能被挖 |
| `HoldTime` | 2 | 通道在挖洞者离开后保持多久（秒） |
| `RefillTime` | 8 | 之后多久长回来（秒） |
| `HoleEdgeNoise` | 0.35 | 洞壁有多毛糙，0 为光滑的管道 |
| `HoleResolution` | 48 | 挖洞网格在盒子最长边上的格数 |

代码里也可以直接调：`Carve(Start, End, Radius, Strength)` 挖一段胶囊，`GetCarving(Point)` 查某点挖掉了多少（0–1），
`ClearCarving()` 让所有洞立刻合上。透射率图跟着挖洞更新，光会照进隧道。

## 质量

| | |
| :-- | :-- |
| `DreamCloud.Quality` | 0 低（步长两倍、透射率图 16 格）· 1 中 · 2 高（默认，32 格）· 3 极高（步长 0.7 倍、48 格） |
| `StepScale` | 单个云体积的细步长倍数（1 为半格） |
| 自动 | 云占屏越大，步子放得越长，最多 1.75 倍 |

## 控制台命令

| 命令 | 作用 |
| :-- | :-- |
| `DreamCloud.Spawn <realistic\|toon\|painted> <sphere\|box\|blob\|cube\|spheremesh\|网格路径> <x> <y> <z> [大小]` | 放一团云。坐标写成 `@前 右 上` 时相对于镜头 |
| `DreamCloud.Set <属性> <值> [名字或标签]` | 像编辑器那样改所有（或名字、标签包含筛选词的）云体积的一个属性，形状变了会重烘 |
| `DreamCloud.CarveView <半径>` | 让镜头挖穿它经过的云，0 为停止 |
| `DreamCloud.Clear` | 删除世界里所有云体积 |
| `DreamCloud.Dump` | 打印每个云体积的场、绘制盒、材质参数、光照和挖洞状态 |
| `DreamCloud.Quality <0–3>` | 质量档 |
| `DreamCloud.UseLightMap <0–4>` | 1 读透射率图（默认）；0 朝光取样对比；2、3、4 为调试视图（步进区间；卡通表面命中位置；卡通步进用掉的步数、是否走到头、是否命中） |

| 方向 | 内容 |

## 限制

- **铺满屏幕的开销**：每个像素都要步进。1920×1080 下（引擎半透明内部分辨率 1400×788）的实测：

  | 场景 | 写实 | 卡通 | 新海诚 |
  | :-- | :-- | :-- | :-- |
  | 镜头在云里 | 约 0.25 ms | 约 0.32 ms | — |
  | 一团云占屏约 60% | 约 0.6 ms | 约 0.4 ms | 约 0.5 ms |
  | 占屏约四分之一 | 约 0.44 ms | 约 0.36 ms | — |

  很多团云同时铺满屏幕时开销叠加。
- **天空光捕获和反射里看不到**：云体积是半透明物体，不进天空光的捕获，也不出现在反射捕获里。
- **大云交给天空**：几公里以上的云层、积雨云用 `ADreamSky` 的云。100 公里的盒子会让步子变粗，而且天空光看不到它。
- **非均匀缩放是近似的**：噪声、边缘、叶团的尺寸按三个轴缩放的平均值换算。
- **透射率图没有鼓包级细节**：云在自己身上的投影只到噪声的低频这一级，鼓包之间互不遮挡。
- **多个云体积重叠时**按半透明物体整体排序，交叠的部分可能前后不对。
